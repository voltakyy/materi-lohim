1️⃣ Modul 1: Konsep Dasar Algoritma, Flowchart & 3 Perintah Komputer

Kata Algoritma diserap dari nama ilmuwan matematika muslim ternama Abu Ja'far Muhammad bin Musa Al-Khawarizmi (penemu Aljabar). Dalam bidang informatika, algoritma didefinisikan sebagai urutan langkah-langkah logis dan terstruktur yang disusun secara sistematis untuk menyelesaikan persoalan komputasi.

5 Karakteristik Mutlak Algoritma (Donald Knuth)

  • Finiteness (Keterbatasan): Algoritma harus berakhir setelah sejumlah langkah berhingga. Tidak boleh looping selamanya tanpa henti!
  • Definiteness (Kepastian): Setiap instruksi harus jelas, eksplisit, dan tidak menimbulkan makna ganda (tidak ambigu).
  • Input (Masukan): Memiliki nol atau lebih data masukan dari luar sistem.
  • Output (Keluaran): Memiliki satu atau lebih hasil keluaran sebagai solusi.
  • Effectiveness (Efektivitas): Setiap langkah harus sederhana dan dapat dikerjakan dalam waktu yang masuk akal.

3 Perintah Dasar Pemrograman (Soal UTS Husni Thamrin)

Setiap program komputer modern pada dasarnya menjalankan 3 operasi fundamental:

  1. Perintah Meminta Data (Input): Menerima data dari pengguna. Di Python menggunakan fungsi input().
  2. Perintah Menyimpan / Menghitung Data (Assignment & Process): Menyimpan nilai ke memori variabel menggunakan operator penugasan = dan memprosesnya dengan ekspresi aritmatika.
  3. Perintah Menampilkan Data (Output): Menyajikan hasil pengolahan ke layar terminal. Di Python menggunakan fungsi print().
# Contoh 3 Perintah Dasar di Python
nama = input("Siapa nama Anda? ")           # 1. Meminta data (Input)
salam = "Halo, Selamat Datang " + nama       # 2. Menyimpan & Memproses (Assignment)
print(salam)                                 # 3. Menampilkan data (Output)

2️⃣ Modul 2: Tipe Data, Variabel & Operator Aritmatika Python

Python adalah bahasa yang berorientasi objek dengan *dynamically typed variables*. Anda tidak perlu mendeklarasikan tipe data secara eksplisit saat membuat variabel.

Tipe Data Dasar Python

  • int: Bilangan bulat (contoh: 10, -5, 0).
  • float: Bilangan berkoma / desimal (contoh: 3.14, 100.5).
  • str: String teks (contoh: "Informatika", 'L200240189').
  • bool: Nilai boolean (True atau False).
⚠️ JEBAKAN POPULER UTS: Tipe Data input()
Fungsi input() di Python SELALU mengembalikan nilai bertipe str (string)!
Jika user memasukkan angka 5, variabel akan bernilai string '5'.
Untuk operasi matematika, WAJIB dikonversi dengan int(input(...)) atau float(input(...))!

3️⃣ Modul 3: String Slicing Komprehensif (Materi Utama UTS)

String di Python diperlakukan sebagai urutan karakter (*sequence*) yang setiap karakternya memiliki indeks numerik tetap.

Aturan Indeks Python

  • Indeks Positif (Kiri ke Kanan): Dimulai dari 0 untuk karakter pertama, 1 untuk karakter kedua, dst.
  • Indeks Negatif (Kanan ke Kiri): Dimulai dari -1 untuk karakter paling belakang, -2 untuk karakter kedua dari belakang, dst.

Sintaks Slicing: teks[start : stop : step]

  • start: Indeks awal pemotongan (inklusif).
  • stop: Indeks batas akhir (eksklusif — karakter di indeks ini TIDAK diikutkan!).
  • step: Langkah lompatan. Jika positif, bergerak maju (kiri ke kanan). Jika negatif, bergerak mundur (kanan ke kiri).
💡 Bedah Rumus Tracing UTS UMS: Z[9:6:-1]
Misalkan string NIM: Z = 'L200240189' (Panjang 10 karakter, indeks 0 sampai 9).
• start = 9: Karakter di indeks 9 yaitu '9'.
• stop = 6: Batas akhir berhenti di sebelum 6 (yaitu indeks 7).
• step = -1: Melangkah mundur 1 langkah per karakter.
Karakter yang diambil berurutan: Indeks 9 ('9'), Indeks 8 ('8'), Indeks 7 ('1').
Hasil potongan: '981' (String 3 karakter terbalik).

4️⃣ Modul 4: Struktur Kontrol Percabangan (if, elif, else)

Percabangan memungkinkan program mengambil keputusan berdasarkan evaluasi kondisi boolean (True atau False).

Aturan Indentasi Python

Berbeda dari C++ atau Java yang menggunakan kurung kurawal { }, Python menggunakan indentasi (spasi/tab) untuk mendefinisikan blok kode di dalam if, for, dan while. 

# Studi Kasus Diskon Kasir Minimarket (UTS 2025)
total_belanja = 125000

if total_belanja > 100000:
    diskon = 0.10 * total_belanja    # Potongan 10% jika belanja > 100k
else:
    diskon = 0                       # Tidak ada diskon jika <= 100k

total_bayar = total_belanja - diskon
print("Total Bayar: Rp", total_bayar)

5️⃣ Modul 5: Struktur Kontrol Perulangan (for, while)

Perulangan digunakan untuk mengeksekusi blok kode yang sama berulang kali selama kondisi terpenuhi atau melintasi elemen koleksi.

Perulangan while (Sentinel Controlled Loop)

Sangat cocok untuk program kasir yang jumlah barangnya tidak diketahui di awal:

total = 0
lanjut = "ya"

while lanjut.lower() == "ya":
    harga = float(input("Harga barang: "))
    qty = int(input("Jumlah barang: "))
    total += harga * qty
    lanjut = input("Ada barang lagi? (ya/tidak): ")

print("Total belanjaan:", total)

Perulangan for dengan range()

range(start, stop, step) menghasilkan barisan bilangan bulat:

  • range(5) $ ightarrow$ 0, 1, 2, 3, 4
  • range(1, 6) $ ightarrow$ 1, 2, 3, 4, 5
  • range(1, 10, 2) $ ightarrow$ 1, 3, 5, 7, 9 (bilangan ganjil)

🛒 Simulator Kasir Minimarket & Alur Flowchart (Soal No. 2 UTS)

Simulasikan sistem transaksi kasir sesuai soal UTS: kasir menginput harga dan jumlah barang, sistem mengakumulasikan total belanja, dan jika total lebih dari Rp 100.000 diberikan diskon 10%.

➕ Input Transaksi Barang

MINIMARKET INFORMATIKA UMS
Subtotal Belanja: Rp 125,000.00
Potongan Diskon (10%): - Rp 12,500.00
TOTAL BAYAR: Rp 112,500.00

🗺️ Alur Flowchart Eksekusi Sistem Kasir

🟢
1. Mulai (Terminator): Program kasir dijalankan. Inisialisasi total = 0.
📥
2. Input Barang (I/O): Menerima masukan harga dan jumlah.
⚙️
3. Akumulasi (Proses): subtotal = harga * jumlah → total += subtotal.
❓
4. Perulangan (Decision): Ada barang lain yang dibeli? (Ya/Tidak).
💎
5. Percabangan Diskon (Decision): Apakah total > 100.000?
🏷️
6. Hitung Diskon (Proses): Jika Ya → diskon = 10% * total. Jika Tidak → diskon = 0.
🖨️
7. Cetak Struk (I/O): Tampilkan rincian total dan kembalian.
🔴
8. Selesai (Terminator): Transaksi berhasil tuntas.
